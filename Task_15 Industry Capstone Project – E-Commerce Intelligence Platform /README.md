# Industry Capstone Project: E-Commerce Intelligence Platform

## Overview
A relational Database Management System (DBMS) built in MySQL to manage end-to-end e-commerce operations—integrating customer profiles, product catalogs, multi-seller inventory, order processing, payment tracking, customer reviews, automated triggers, query optimization, and business intelligence reporting.
